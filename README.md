# Estudos de React

Este repositório contém um projetos e códigos simples de estudos desenvolvido com **React.js**, como parte do meu processo de aprendizado da biblioteca.&#x20;

---

## 📚 Contexto

Estes projetos foram realizados como parte dos exercícios propostos na plataforma [Hora de Codar](https://www.horadecodar.com.br/), com o objetivo de praticar:

* Conceitos básicos de React
* Criação e uso de componentes
* Manipulação de estados (`useState`)
* Eventos de formulário (`onChange`, `onClick`, `onSubmit`)
* Condicional de renderização
* Estilização com CSS
* Organização de pastas e arquivos em projetos React

---

## 🚧 Aviso

Este projeto **não tem fins comerciais ou de publicação**.
É **apenas um exercício prático** para fins de aprendizado e domínio da biblioteca React.
Se você está explorando o repositório, sinta-se à vontade para clonar, testar e estudar!
